# Fahad Ibrahim

Developer and venture builder based in Dhaka, Bangladesh. I build practical web products and interactive experiences, with a focus on useful software for people and businesses. I’m building Hope Theory Labs and am open to remote development opportunities.

## Selected work

These are the six projects I’m focusing on publicly:

- [Hope Theory Labs](https://github.com/FahadIbrahim93/hopetheorylabs-site) — Company website and studio presence. [Visit the live site](https://hopetheorylabs.vercel.app/).
- [EMBERFALL](https://github.com/FahadIbrahim93/emberfall) — Browser-based arcade space shooter with offline play, accessibility options, and leaderboards. [Play](https://emberfall-game-two.vercel.app/).
- [Portfolio](https://github.com/FahadIbrahim93/FahadIbrahim93.github.io) — My portfolio, case studies, and contact information. [Visit the site](https://fahadibrahim93.github.io/).
- [Hishab Sathi](https://github.com/FahadIbrahim93/Hishabh-Sathi) — Bangla-first, offline-first bookkeeping and stock management for Bangladeshi shops and distributors.
- [Web Development with AI](https://github.com/FahadIbrahim93/web-development-with-ai) — Interactive course platform for non-technical people learning to build websites with AI. [Try the demo](https://web-development-with-ai-indol.vercel.app/).
- [RollON](https://github.com/FahadIbrahim93/RollON-MVP-Final-V1) — E-commerce storefront template with catalog, cart, checkout demo, and admin dashboard. [View the demo](https://rollon-delta.vercel.app/).
